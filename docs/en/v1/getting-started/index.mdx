You are reading **Ridge v1**. It is in maintenance mode. Bug fixes land here; features land in [v2](/en/docs/v2/getting-started).

<Callout type="warning" title="Lockfile versions do not mix">
A v1 `ridge.lock` (`lockfileVersion: 1`) cannot be installed with the v2 CLI unless you run `ridge migrate`. Keep the CLI on 1.9.x for this branch.
</Callout>

## What is different in v1

- The lockfile is JSON, not YAML
- `hoist` defaults to `worktree`
- Nested workspaces are not discovered unless listed explicitly
- `ridge gc` is opt-in in CI
